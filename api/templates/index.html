🛵 delivery-eta API

가게에서 배달지까지의 거리와 밀려 있는 주문 수로 배달 예상 시간(분)을 알려 주는 API 입니다.

model __MODEL_IMPL__ FastAPI

엔드포인트

GET/health

서비스 상태와 현재 쓰고 있는 예측 구현체 이름을 돌려줍니다.

{"status": "ok", "model": "__MODEL_IMPL__"}
POST/eta

배달 예상 시간을 계산합니다. 두 값 모두 0 이상이어야 하며, 아니면 422 를 돌려줍니다.

curl -X POST /eta \
  -H "Content-Type: application/json" \
  -d '{"distance_km": 2.5, "pending_orders": 3}'

→ {"minutes": 23.5, "model": "__MODEL_IMPL__"}
